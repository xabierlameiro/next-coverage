# Security policy

`next-coverage` reads the files of the project you point it at. It does not build or run that
project, install anything, or make network requests.

## Supported versions

Only the latest release receives fixes while the project is in `0.x`.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/xabierlameiro/next-coverage/security/advisories/new)
for this repository, with the version, what you ran, and what happened. You will get an answer
within a week.
